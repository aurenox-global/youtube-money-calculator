Política de Privacidad

Aplicación: Phone Stats Manager · Última actualización: 2 de octubre de 2026

1. Qué es esta aplicación

Phone Stats Manager es una utilidad personal de gestión de canal de YouTube. Se conecta a tu propia cuenta de YouTube mediante la autorización OAuth de Google para consultar y gestionar el canal que tú autorizas expresamente.

2. Qué datos utiliza

  • Datos de tu canal y tus vídeos obtenidos vía la YouTube Data API (por ejemplo: título, descripción, estadísticas públicas, listado de vídeos).
  • Permisos de gestión (subir/editar/borrar vídeos y playlists) solo sobre el canal que autorices, con el alcance youtube.force-ssl.

3. Cómo se usan

Los datos se emplean exclusivamente para realizar las acciones que tú solicitas sobre tu propio canal. No se venden, alquilan ni comparten con terceros.

4. Almacenamiento y seguridad

Los tokens de acceso se guardan de forma local y protegida (permisos restringidos) en el equipo del usuario. No se publican ni se comparten.

5. Revocar el acceso

Puedes revocar el acceso en cualquier momento desde tu cuenta de Google → Permisos de apps.

6. Contacto

Para cualquier duda: phonworldres@gmail.com

Esta aplicación usa los Servicios API de YouTube. Al usarla aceptas las Condiciones del Servicio de YouTube.
